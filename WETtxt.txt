--- Q1. PHP: prime number using function + default parameter (slip2_q1.php) ---
<?php
function isPrime($n = 7) {          // default parameter
    if ($n < 2) return false;
    for ($i = 2; $i <= sqrt($n); $i++) {
        if ($n % $i == 0) return false;
    }
    return true;
}

echo "Default (7): " . (isPrime() ? "Prime" : "Not Prime") . "<br>";
$num = 29;
echo "$num is " . (isPrime($num) ? "Prime" : "Not Prime");
?>

--- Q2. PHP: read Item.dat and display Bill (slip2_q2.php) ---
First create Item.dat in the same folder (format: code,name,units,rate):
101,Pen,10,5
102,Notebook,5,40
103,Pencil,20,3
104,Eraser,8,4
105,Marker,3,25

<?php
$file = fopen("Item.dat", "r");
echo "<table border='1' cellpadding='6' style='border-collapse:collapse'>";
echo "<tr><th>Code</th><th>Name</th><th>Units Sold</th><th>Rate</th><th>Amount</th></tr>";
$total = 0;
while (($line = fgets($file)) !== false) {
    $line = trim($line);
    if ($line == "") continue;
    list($code, $name, $units, $rate) = explode(",", $line);
    $amt = $units * $rate;
    $total += $amt;
    echo "<tr><td>$code</td><td>$name</td><td>$units</td><td>$rate</td><td>$amt</td></tr>";
}
echo "<tr><th colspan='4'>Total Bill</th><th>$total</th></tr>";
echo "</table>";
fclose($file);
?>

Q3. VIVA - QUICK NOTES (common questions asked in every slip)
=====================================================================
1. PHP = Hypertext Preprocessor, server side scripting language. File ext: .php
2. PHP code is written inside <?php ... ?>
3. Variables start with $ ; echo / print are used for output.
4. Array types: indexed, associative, multidimensional.
5. Useful array functions: count(), array_merge(), sort(), asort(), arsort(),
   ksort(), in_array(), array_key_exists(), array_reverse(), extract().
6. String functions: strlen(), strrev(), strpos(), strtolower(), strtoupper(), explode(), implode().
7. File modes: r (read), w (write/overwrite), a (append), r+ (read/write).
8. File functions: fopen(), fclose(), fgets(), fwrite(), feof(), file_exists(),
   filesize(), copy(), unlink() (delete), file_get_contents().
9. GET vs POST: GET shows data in URL; POST hides data (more secure).
10. preg_match() = checks a regular expression pattern.
11. HTML = HyperText Markup Language. CSS = Cascading Style Sheets.
12. Types of CSS: Inline (style attribute), Internal (<style> tag), External (.css file with <link>).
13. JavaScript is a client side scripting language. Output: alert(), document.write(), innerHTML.
14. Events: onclick, onmouseover, onchange, onload.
15. Difference between == and === : == compares value, === compares value and type.
